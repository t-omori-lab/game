# Game Brief: 小さな永続世界ローグライト

Last updated: 2026-07-30

## Product promise

短い遠征でビルドを作り、自分の成功・失敗・落とした装備が次の旅人の世界へ残る、スマホでも遊べる小さな永続世界ゲームを作る。

## Prototype 0.1 status

実装済み:

- 移動、自動攻撃、脈動スキル、敵3種、エリート、ボス。
- 経験値、3択強化、勝敗、再調査。
- 討伐跡、累計遠征、最高討伐数の次回継承。
- iPhone横画面向けのベクターUI、PWA shell、version付きA/B保存。

未実装:

- 拠点、進路3本、遺物、賞金首、撤退判断。
- 宿敵が死亡旅人の装備を拾い、次回に奪還する仕組み。
- 妖怪／荒野の正式選定、AIによる検査済みコンテンツ生成。
- 実機iPhoneの10分性能合格、Steam包装。

## Confirmed taste signals

- 放浪し、生き方や目的を自分で選べる。
- 選ばれた英雄ではない人物から始まる。
- 装備、能力、乗り物を組み合わせて強くなる。
- 賞金首や遺物のように、世界内に具体的な目標が存在する。
- 世界がプレイヤーの外でも続いているように感じられる。
- 豪華な素材量ではなく、仕組みと繰り返しで長く遊べる。
- 計算で描く線、円弧、多角形、粒子を中心にしつつ、画面として美しい。

## First playable loop

### 30 seconds

1. 敵と地形の予兆を読む。
2. 移動、自動攻撃、能動スキル1個で対応する。
3. 戦利品を一時強化、修理、持ち帰りから選ぶ。

### 8 minutes

1. 初期装備を選ぶ。
2. 敵群を避けるか倒して資源を得る。
3. 3回の強化選択でビルドを作る。
4. 強敵へ挑むか、安全に撤退する。
5. 結果が次回の世界状態へ残る。

### Multiple runs

- 死亡した旅人の装備を宿敵が拾う。
- 次の旅人は、その装備を奪還できる。
- 前回の結果は、次回開始90秒以内に地形、敵、価格、配置のいずれかで見える。

## First-slice scope

- 拠点1、探索地域1、進路3。
- 通常敵3種、エリート1種、ボス1体。
- 武器コア3、強化6、明確な相乗効果3組。
- 賞金首1体。
- 次回へ残る世界変化1系統。
- 横画面、論理解像度960×540。
- 基準端末はiPhone 16 Pro。

## Theme abstraction

初期コードでは、世界観を次の抽象語彙で扱う。

| Internal concept | 妖怪案 | 荒野案 |
|---|---|---|
| traveler | 旅人、退魔師、流れ者 | 賞金稼ぎ、運び屋 |
| carrier | 付喪神、妖怪の乗り物 | 車両、機械、生物 |
| anomaly | 妖怪、怪異 | 変異生物、暴走機械 |
| relic | 札、器、記憶 | スクラップ、部品、遺物 |
| contract | 退治、封印、回収 | 討伐、回収、護送 |

第5週までに同じゲームへ2案を仮着せし、操作性、視認性、固有性で1案に絞る。

## Visual direction

- 「動く地図／図鑑」のような画面。
- 5色前後の強いパレットと太い輪郭。
- 敵は遠目でも区別できる形状文法を持つ。
- 攻撃は弧、扇、輪、軌跡、脈動で示す。
- 道、轍、残骸、討伐印を世界履歴として地図に残す。
- 生成形状はキャッシュし、毎フレーム頂点を作り直さない。

## AI boundary

- 初期戦闘の判定、数値、報酬、世界状態に生成AIを使わない。
- 第4週以降、名前、噂、依頼文、形状パラメータ、来歴の候補生成に使う。
- AI出力はschema検査と人間の採否を通したJSONだけを収録する。
- ライブ生成、自由会話、クライアントへのAPIキー埋め込みは初版対象外。

## Success gates

- 30秒以内に説明なしで移動と戦闘が成立する。
- 8分遊んだ後、自発的に2回目を始めたくなる。
- 少なくとも3つの異なるビルド方針が成立する。
- 前回の行動による世界変化を次回90秒以内に認識できる。
- iPhone 16 Proで10分間、操作不能や継続的な30fps未満がない。
- 15遠征でクラッシュ、進行不能、セーブ破損が0件。

## Non-goals for the first release

- 広大なシームレス世界。
- 全NPCの常時生活シミュレーション。
- 仲間パーティー、拠点建築、複雑なクラフト。
- 長文AI会話、マルチプレイ。
- App Store、Google Play、Steam実績、Steam Cloudの同時対応。
